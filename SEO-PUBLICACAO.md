# Publicação e busca

Sem domínio definido, canonical, og:url, URLs absolutas de imagem e sitemap ficam pendentes para evitar indexar um endereço incorreto. Ao publicar, configure esses campos com o domínio HTTPS real, gere sitemap.xml e informe sua URL no robots.txt. Valide os dados estruturados no Rich Results Test e cadastre o domínio no Google Search Console para solicitar indexação.

Botão de avaliação abre o perfil da academia no Maps. Para abrir diretamente o formulário, substituir pelo link oficial de solicitar avaliações do Perfil da Empresa (ou link com Place ID confirmado).

Dados estruturados HealthClub incluem nome, endereço, telefone e horários. Sem marcação de estrelas próprias para resultados enriquecidos, conforme orientações do Google. Não há garantia de posição nas buscas.
